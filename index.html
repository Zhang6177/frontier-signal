Mimir: Physics-Grounded LLM Agents for Long-Horizon Irrigation Control

一句话看懂物理接地 LLM 灌溉控制 agent，综合控制成本最低，较历史调度节水 51%

Hermes 速读Hermes AI Paper Cron 每日生成 · 统一情报摘要模板
研究动机

长程物理控制中动作改变未来状态、错误跨决策复合，LLM agent 研究空白

核心问题

LLM 输出不能直接驱动执行器，现有 agent 无法在长时程物理系统中安全自改进

主要贡献
  • 提出双时间尺度物理接地 LLM agent Mimir
  • 快环：LLM 提案经确定性土壤-水分仿真数值校验后执行
  • 慢环：反复失败模式蒸馏为持久上下文原则
创新点
  • 分离推理权威与物理权威：LLM 永不直接成为执行器命令
  • 有界自改进：经验只改推理上下文，不改物理模型与动作约束
  • 发现 LLM 规模无单调收益，控制架构比模型大小更关键
方法概述

确定性模型给出可行动作域→LLM 提案/修订→程序化仿真暴露后果→有界确定性选择器→运行时保障终审；慢环把反复修正沉淀为持久原则。

实验结果

密歇根/德州/科罗拉多多年回溯评测：综合控制成本最低、灌溉量较历史回放少约 51%；配对消融——去前向仿真成本 149.5→730.5，去决策修复 109.1→180.5，去持久上下文 103.0→157.5。

论文价值

给出 LLM+物理系统的治理模板，语义推理与数值权威严格分权

核心问题

遮挡下波形拟合良态但几何不良态：宽峰也可由位移单面等价解释

主要贡献
  • 首个仅用遮挡测量做前景视图+隐藏场景重建的研究
  • 每射线回波证据状态估计，路由双头神经场监督
  • 首个真实配对多视角 SPL 遮挡数据集（30 场景/3 材质/10 类物体）

  • 明确证明"瞬态拟合准≠分层几何对"

研究动机

RFM 流匹配多步去噪延迟高，动作头占端到端推理 40~50% 时间

核心问题

MeanFlow 直接用于通才 RFM 会性能崩溃，已有变体只在专家策略上验证

主要贡献
  • 发现 RFM 速度场两动态：后期局部加速度骤升、样本间展宽
  • K-MF：运动学恒等式把 MeanFlow 时间导数项解耦为两子区间项
  • 从零训练与微调两范式验证单步动作生成
创新点
  • 首次系统诊断 MeanFlow 在通才 RFM 上崩溃的机理
  • 解耦后两项分别捕捉早/晚去噪动态，抑制误差跨步放大
方法概述

引入中间点把时间导数项拆成两子区间项，分别拟合稳定早段与骤升晚段；可学习中间点策略（3 层 MLP 生成器）。

实验结果

NFE=1 接近 NFE=4 流匹配：LIBERO 97.9% vs 97.3%，Simpler-Google 78.4% vs 73.9%；GR00T-N1.6 动作头延迟 −67.5~74.4%，端到端 −30.3~54.9%（L40/Jetson Orin）。

论文价值

移除 RFM 实时部署最大瓶颈，一步动作生成不牺牲精度

Clock Diffusion: Efficient Semi-Autoregressive Continuous Diffusion Language Models

一句话看懂半自回归连续扩散语言模型，首个可比块离散扩散 PPL 且支持 KV 缓存

Hermes 速读Hermes AI Paper Cron 每日生成 · 统一情报摘要模板
研究动机

连续扩散 LM 性能已近离散扩散，但无法变长生成、不支持 KV 缓存

核心问题

全序列连续模型不可实用化，质量仍落后 AR 与 SAR 离散扩散

主要贡献
  • Clock Diffusion：位置相关噪声调度（局部时钟）定义 SAR 连续 DLM
  • ClockDLM 家族：滑动窗口高斯 DLM+高效训练采样
  • Cache Grab 采样器：置信 token 提交+自投机解码
创新点
  • 首个支持变长生成+KV 缓存的连续 DLM
  • 连续 DLM 中 PPL 达 SOTA，甚至超过块式离散扩散
方法概述

把全局扩散时间参数化为位置相关局部时钟，块/滑动窗口两种生成模式；滑窗版本每轮更新 KV 缓存。

实验结果

OpenWebText PPL 连续模型 SOTA（胜块式 SAR 离散扩散），较 BD3LM 将 PPL 与 AR 基线差距缩小约 38%；TinyGSM 训练 GSM8K 66.6~67.2%，超 AR 基线 64.3%；较此前连续 DLM 准确率最高提升 33%。

论文价值

连续扩散 LM 从玩具走向实用，打开 AR 与离散扩散之外的第三条路线
